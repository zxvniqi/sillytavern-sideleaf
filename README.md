# 별지 · Sideleaf

QR 결과나 따로 읽을 메시지만 골라, 현재 대화에서 빼두는 SillyTavern 확장입니다. 채팅마다 보관함이 나뉩니다.

## 설치

SillyTavern **확장 → Install extension**에 아래 주소를 넣고 설치한 뒤 새로고침하세요.

```
https://github.com/zxvniqi/sillytavern-sideleaf
```

SillyTavern 1.19.0 이상을 대상으로 합니다. 별도 서버 플러그인이나 빌드가 필요하지 않습니다.

## 사용

- 메시지의 **별지에 보관** 아이콘으로 바로 보관하거나, **마법봉 → 별지 → 메시지 선택**에서 여러 개를 고릅니다. `/sideleaf`로도 열 수 있습니다.
- 원문·번역·수정본을 선택해 읽고 복사할 수 있습니다. 제목과 본문 수정 아이콘은 메시지를 펼치면 보입니다. 제목만 수정해도 수정본이 생기지 않습니다.
- 크게 읽기에서는 좌우 버튼·방향키·가로 스와이프로 넘깁니다. 목록 팝업에서 골라도 큰 화면이 유지됩니다.
- 상단 **편집 모드**에서 전체 선택, 복원, 정렬, 직접 순서 변경과 통합 백업을 사용합니다. 전체 선택은 검색 결과의 모든 페이지에 적용됩니다.
- 복원은 해당 채팅의 끝에 원본 메시지를 추가합니다. 읽기용 수정본으로 원문을 덮어쓰지 않습니다.
- 일반 QR 버튼을 눌러 실행한 결과는 QR 이름을 제목으로 사용합니다. 실행 중 기본 입력 팝업에서 확인한 주제가 있으면 주제를 우선합니다. 자동 실행·스크립트 호출·커스텀 팝업은 자동 연결을 보장하지 않습니다.

## 저장과 백업 — 꼭 읽어주세요

**별지 본문은 같은 SillyTavern 서버의 계정별 파일에 따로 저장됩니다. 채팅에는 작은 연결 정보만 남습니다.** 별지를 열거나 보관 작업을 할 때 필요한 보관함을 불러오며, 일반 채팅 로딩·저장 때 본문을 매번 읽지 않습니다. 별지를 닫으면 확장이 보유한 보관함 캐시를 비웁니다.

기존 채팅 안에 저장된 보관본도 읽을 수 있습니다. 편집 모드의 **분리 저장으로 전환**을 누르거나 보관·수정·복원 작업을 하면 분리 저장으로 전환합니다. 새 파일을 다시 읽어 검증한 뒤 채팅 연결을 변경합니다. 최초 전환에는 보관함 크기에 따른 시간이 필요합니다.

**분리 저장 후 일반 채팅 JSONL 내보내기에는 별지 본문이 포함되지 않습니다.**

- 다른 서버로 옮길 때는 **편집 모드 → 채팅·별지 통합 백업**을 사용하세요. 활성 채팅과 보관본 전체를 하나의 JSONL에 담습니다.
- 통합 백업을 SillyTavern의 채팅 가져오기로 불러오면 별지에서 다시 읽을 수 있습니다. 이후 변경 시 새 서버에 분리 저장합니다.
- 서버 전체 백업을 사용할 때는 해당 계정의 채팅 파일과 `files` 폴더의 `sideleaf-*.json` 파일들을 함께 보존하세요. 메시지에 연결된 이미지·첨부 파일 원본은 별도 서버 백업이 필요합니다.
- 연결 정보만 있는 일반 채팅 파일로는 별지 파일이 없는 서버에서 본문을 복구할 수 없습니다. 별지 파일을 임의로 지우지 마세요.
- 분기한 채팅과 이전 백업의 연결을 보호하기 위해 과거 저장 파일을 자동 삭제하지 않습니다. 일반 채팅 처리 부담은 줄지만 서버 저장 공간이 줄어든다는 뜻은 아닙니다.
- 백업에는 개인 대화 내용이 들어갑니다. 오류 제보나 공개 게시물에 그대로 올리지 마세요.

파일 저장이나 서버 확인에 실패하면 성공으로 표시하지 않습니다. 채팅 저장을 확인하지 못한 경우 재시도와 통합 복구 백업을 제공합니다. 여러 기기에서 같은 채팅을 동시에 수정하는 상황은 SillyTavern의 충돌 처리 범위를 따릅니다.

## 성능과 호환 범위

- 보관 개수의 고정 상한은 없습니다. 페이지당 30개, 긴 본문은 20,000자씩 표시합니다. 보관함을 열 때의 로딩·검색 비용은 전체 보관본 크기에 영향을 받습니다.
- 제목·순서 변경은 원문 파일을 재사용합니다. 수정 본문은 원문과 별도로 저장합니다.
- 다른 확장이 없어도 사용할 수 있습니다. 기존 메시지 액션과 마법봉을 대체하지 않으며 스타일은 별지 영역으로 제한합니다. 읽기 화면은 현재 채팅의 글꼴과 배경을 반영합니다.
- 저장된 번역·표시문을 우선 표시합니다. 해당 필드가 없는 경우 보관 당시 메시지 화면의 텍스트를 함께 저장합니다. 별지가 번역 요청을 보내지는 않으며 iframe 내부나 로드되지 않은 메시지는 캡처하지 못합니다.
- HTML·QR·매크로를 보관함에서 다시 실행하지 않습니다. 접힌 details의 본문도 텍스트로 읽습니다. 다른 확장의 대화형 화면을 그대로 재현하지는 않습니다.
- 보관한 메시지는 활성 대화에서 빠집니다. 이미 다른 확장이 만든 요약·장기기억·벡터 기록까지 소급해서 지우지는 않습니다.
- 확장을 꺼도 보관본이 자동 복원되지는 않습니다. 활성 대화에는 메시지를 하나 이상 남겨야 합니다.

## 개발 확인

`npm test`로 데이터 보존·복원·분리 파일·백업 왕복·QR 연결 검사를 실행합니다. 검증 범위는 `TESTING.md`를 참고하세요.
