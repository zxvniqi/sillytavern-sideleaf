# 별지 · Sideleaf (베타)

필요한 메시지만 골라 대화에서 빼두고, 채팅별 보관함에서 따로 읽는 SillyTavern 확장입니다.
보관한 메시지는 AI에게 보내는 대화 기록에서 빠집니다.

## 설치

SillyTavern **확장 → Install extension**에 아래 주소를 넣고 새로고침하세요. (SillyTavern 1.19.0 이상)

```
https://github.com/zxvniqi/sillytavern-sideleaf
```

## 사용

- 메시지 메뉴의 **★** 또는 **마법봉 → 별지**(`/sideleaf`)
- 보관함에서 읽기·복사·제목/본문 수정, **편집**에서 복원·순서 변경·통합 백업

## 주의

- 베타입니다. 중요한 채팅은 먼저 **편집 → 통합 백업**을 받아두세요.
- 별지 본문은 서버의 별도 파일에 저장되어, 일반 채팅 내보내기에는 들어가지 않습니다. 옮길 때는 통합 백업을 쓰세요.
- 복원한 메시지는 채팅 끝에 붙습니다.
