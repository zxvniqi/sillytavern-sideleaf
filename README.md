# 별지 · Sideleaf (베타)

필요한 메시지만 골라 대화에서 빼두고, 채팅별 보관함에서 따로 읽는 SillyTavern 확장입니다.
보관한 메시지는 AI에게 보내는 대화 기록에서 빠집니다.

## 설치

SillyTavern **확장 → Install extension**에 아래 주소를 넣고 새로고침하세요. (1.19.0에서 확인 · 이전 버전은 미확인)

```
https://github.com/zxvniqi/sillytavern-sideleaf
```

## 사용

- 메시지 메뉴의 **★** 또는 **마법봉 → 별지**(`/sideleaf`)
- 보관함에서 읽기·복사·제목/본문 수정·삭제, **편집**에서 여러 개 복원·삭제·순서 변경·통합 백업

## 주의

- 베타입니다. 중요한 채팅은 먼저 **편집 → 통합 백업**을 받아두세요.
- 별지 본문은 서버의 별도 파일에 저장되어, 일반 채팅 내보내기에는 들어가지 않습니다. 옮길 때는 통합 백업을 쓰세요.
- 본문 수정은 보고 있는 본문(원문·번역)을 바로 고칩니다. 원문을 고치면 복원할 때도 고친 내용이 돌아갑니다.
- 복원은 보관 전 원래 자리 또는 채팅 끝을 고를 수 있습니다(그 사이 대화가 줄었으면 끝에 붙음). 삭제는 대화로 돌아오지 않고 별지에서 사라집니다.
