# 별지 · Sideleaf

QR 결과나 별도로 보관할 메시지만 골라 현재 대화에서 빼두는 SillyTavern 확장입니다.

## 설치

SillyTavern **확장 → Install extension**에 다음 주소를 입력하세요.

```
https://github.com/zxvniqi/sillytavern-sideleaf
```

설치 후 새로고침하세요. SillyTavern 1.19.0 이상을 대상으로 합니다. 별도 서버 플러그인과 빌드 과정은 필요하지 않습니다.

## 사용

1. 저장된 캐릭터 채팅 또는 그룹 채팅을 엽니다.
2. 입력창 옆 **마법봉 → 별지**를 누릅니다. `/sideleaf`로도 열 수 있습니다.
3. **메시지 선택**에서 필요한 메시지만 체크하고 **보관**을 누릅니다.
4. **보관함**에서는 메시지를 하나씩 펼쳐 읽습니다. 다른 채팅의 보관본은 섞이지 않습니다.
5. 선택한 보관본을 **복원**하면 해당 채팅의 **끝**에 추가됩니다. 이후 수정된 대화의 원래 위치를 임의로 추정하지 않습니다.

본문·이름 검색, 페이지 이동, 선택 보관·복원에 집중했습니다. 자동 보관이나 일괄 삭제 기능은 없습니다. 전체 메시지를 한꺼번에 보관할 수 없으며, 대화에 하나 이상을 남겨야 합니다.

## 저장과 기록

### 0.2.0 — 바로 보관하고 편하게 읽기

- 채팅 메시지의 액션 영역에 **별지에 보관** 버튼이 생깁니다. 마법봉을 열지 않고 해당 메시지만 보관합니다. 테마에 따라 메시지 액션을 펼쳐야 보일 수 있습니다.
- 저장된 `extra.display_text`가 있으면 **번역·표시문**을 먼저 보여줍니다. 기존 보관본에도 적용됩니다. 원문은 본문 선택 메뉴에서 볼 수 있습니다.
- 표시문 필드가 없는 확장은 보관할 때 화면에 렌더링된 해당 메시지 본문을 **보관 당시 화면**으로 함께 저장합니다. 화면에 로드되지 않은 메시지나 iframe 내부 번역은 캡처하지 않습니다. 별지가 새 번역 요청을 보내지는 않습니다.
- **제목 수정**과 **본문 수정**을 따로 제공합니다. 제목만 수정하거나 본문을 바꾸지 않고 저장하면 새 수정본을 만들지 않습니다. 원문과 번역문은 보존되며, **채팅 복원 시에는 원본 메시지**를 사용합니다.
- **복사**는 현재 선택한 본문 전체를 복사합니다. 제목과 번역문, 수정본도 검색할 수 있습니다.
- 자동 펼침은 없습니다. 검색 결과가 하나여도 접힌 목록으로 유지하며, 직접 펼쳐 읽거나 **크게 읽기**로 넓게 볼 수 있습니다. 긴 본문은 계속 나눠 표시합니다.

### 저장 방식

- 보관한 메시지 객체 전체(스와이프와 확장 필드 포함)를 현재 채팅의 `chat_metadata.sideleaf_v1`에 저장하고, 활성 `chat` 배열에서 제거합니다.
- 따라서 기본 대화 화면과 이후 기본 AI 대화 기록에서 빠집니다. 단순 CSS 숨김이 아닙니다.
- 저장본은 채팅 파일과 함께 서버에 남으며, 원본 JSONL 내보내기·백업에 포함됩니다. 브라우저 로컬 저장소에만 의존하지 않습니다.
- 채팅 파일 자체를 삭제하면 그 채팅의 서랍도 함께 사라집니다. 확장을 꺼도 보관본이 활성 대화로 돌아오지는 않으며, 다시 켜면 열 수 있습니다.
- 보관 전에 이미 만들어진 요약·장기기억·벡터·프롬프트 로그에 들어간 내용을 소급해서 지우지는 않습니다. 그러한 별도 기억까지 제외하려면 해당 확장에서 관리해야 합니다.
- 파일 저장 후 서버에서 보관함 revision을 다시 읽어 확인합니다. 실패하면 성공으로 표시하지 않고 재시도와 전체 채팅 JSONL 백업을 제공합니다. 백업 후 닫으면 변경 내용은 현재 메모리에 남으며, 필요할 때 백업을 새 채팅으로 가져올 수 있습니다.
- 여러 브라우저가 같은 채팅을 동시에 편집하는 상황은 SillyTavern 자체의 충돌 처리 범위를 따릅니다.

## 성능과 호환

- 페이지당 30개, 긴 본문은 펼칠 때 20,000자 단위로 표시합니다.
- 주기적인 메시지 전체 스캔·타이머·스트리밍 토큰 감시는 없습니다. QR 실행 중에만 기본 입력 폼의 실행 상태 클래스 변경을 관찰하며 종료 시 해제합니다.
- 스타일은 전용 ID 아래로 제한하고 SillyTavern 테마 색을 따릅니다.
- 기존 메시지 액션이나 마법봉 항목을 대체하지 않습니다.
- 보관함은 원문 텍스트로 표시합니다. HTML·iframe·QR 스크립트·매크로를 다시 실행하지 않습니다. 첨부 파일과 추가 데이터는 복원을 위해 보존하지만 보관함에서 실행하거나 재생하지 않습니다.
- 보관함 데이터는 채팅 메타데이터이므로 채팅 로딩·저장 시 함께 처리됩니다. 대용량 보관본의 서버 저장 비용까지 없어지는 구조는 아닙니다.

## 0.2.1 읽기·검색 개선

- 창을 화면 크기에 맞춰 넓히고 크게 읽기에서는 목록 조작 영역을 숨깁니다.
- 실제 채팅 영역의 계산된 글꼴·크기·글자색·배경을 열 때 반영합니다. 제3자 확장의 스크립트와 HTML 실행을 복제하지는 않습니다.
- 한글 조합 입력 중에는 검색으로 화면을 재생성하지 않으며, 검색 후에도 결과를 자동으로 펼치지 않습니다.
- 이전 버전에서 제목 변경 때문에 생긴 원문/번역과 동일한 수정본은 읽기 메뉴에서 중복 표시하지 않습니다. 저장 데이터는 보존합니다.

## 0.3.0 간결한 조작과 메시지 이동

- 읽기 도구는 아이콘으로 표시합니다. 마우스를 올리면 설명이 나오며 키보드·스크린리더용 이름도 제공합니다. 접힌 종이와 잎을 결합한 별지 아이콘을 사용합니다.
- 상단 연필 **편집 모드**에서 전체 선택, 복원, 정렬과 순서 이동 도구를 표시합니다. **전체 선택은 현재 검색 결과의 모든 페이지**에 적용됩니다.
- 보관 시각 기준 최신순·오래된순과 직접 정한 순서를 지원합니다. 손잡이를 끌어 대상 앞에 놓거나 **순서 이동**에서 전체 보관함의 위치 번호를 지정합니다. 직접 정한 순서는 채팅마다 저장되며 새 보관본은 앞에 추가됩니다. 표시 순서를 바꿔도 복원 순서는 바뀌지 않습니다.
- 크게 읽기에서 좌우 버튼·방향키·터치 가로 스와이프로 넘깁니다. 목록 아이콘을 누르면 검색 가능한 목록 팝업이 열리며, 항목을 선택해도 큰 화면을 유지합니다. 현재 목록의 검색·정렬 범위를 따릅니다.
- 일반 QR 버튼 클릭 이후 생성된 메시지는 QR 이름을 제목으로 사용합니다. 실행 중 기본 입력 팝업에서 확인한 첫 번째 내용이 있으면 그 내용을 우선합니다. 별지 설치 전 생성된 메시지, 자동 실행·스크립트 호출·컨텍스트 메뉴 실행, 별도 커스텀 입력창은 자동 연결을 보장하지 않습니다. 제목은 수동 수정할 수 있습니다.
- QR 스크립트는 읽거나 교체하지 않으며 QR 확장이 없어도 다른 기능은 동작합니다. 실행 중 채팅 변경·취소·일반 입력 시 추적을 해제하며, 명령형 QR은 명령 실행 종료까지 결과를 연결합니다.
- 보관 개수의 고정 상한은 없습니다. 30개는 화면 표시 단위입니다. 활성 메시지를 별지로 옮기는 구조이며, 원문이 두 영역에 동시에 남지는 않습니다. 번역·읽기용 수정문·스와이프는 보존하므로 파일 크기에 영향을 줍니다.
- 크게 읽기의 이전·다음 전환에서는 보관함 전체 정렬·검색을 반복하지 않습니다. 검색은 본문들을 하나의 큰 문자열로 합치지 않고 순차 확인합니다. 채팅 파일 전체를 저장하는 SillyTavern 구조의 비용은 남습니다.


## 0.3.1 수정

- 제목·본문 수정 아이콘을 편집 모드 밖에서도 표시합니다. 메시지를 펼치거나 크게 읽기에서 바로 사용할 수 있습니다.
- QR 자체의 프로그램 전송을 일반 수동 전송으로 오인해 제목 추적을 끊던 문제를 수정했습니다.
- 명령형 QR의 생성이 끝난 뒤 메시지를 따로 붙이는 경로와 사용자/시스템 메시지 출력 경로를 보완했습니다. QR 실행 함수를 교체하지 않습니다.
- 이미 제목 연결 정보 없이 저장된 결과는 자동으로 거슬러 추정하지 않습니다. 수정 버전 적용 후 새로 실행한 QR부터 적용됩니다.

## 0.3.2 접힌 QR 본문 읽기 수정

- 접힌 HTML details를 보관할 때 제목만 캡처하던 문제를 수정했습니다. 안쪽 본문과 중첩된 접기 영역의 텍스트도 포함합니다.
- 기존 보관본에서 details의 화면 캡처가 불완전할 수 있으면 보존된 원문을 먼저 표시합니다. 저장된 원본을 덮어쓰거나 삭제하지 않습니다.
- details 마크업은 분리된 비활성 템플릿에서 텍스트로 읽습니다. 스크립트·스타일·iframe·조작 버튼을 실행하거나 본문으로 표시하지 않습니다.
